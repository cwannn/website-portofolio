# 🌐 Personal Portfolio Website

> Website portofolio pribadi yang dirancang responsif dan interaktif untuk menampilkan profil, keahlian teknis, pengalaman, serta kumpulan proyek yang telah dikembangkan.

---

## 🌟 Fitur Utama

- 📱 **Fully Responsive Design:** Tampilan adaptif dan optimal di berbagai ukuran layar (*desktop*, tablet, maupun *smartphone*).
- 👨‍💻 **About & Skills Showcase:** Bagian khusus yang merangkum latar belakang, pendidikan, serta penguasaan teknologi dan *tools*.
- 🚀 **Project Gallery:** Katalog proyek unggulan lengkap dengan deskripsi singkat, *tech stack*, serta tautan langsung menuju repositori GitHub atau *live demo*.
- 📩 **Contact & Social Integration:** Tautan cepat menuju profil profesional (GitHub, LinkedIn, Email) serta formulir kontak interaktif.

---

## 🛠️ Tech Stack

*(Sesuaikan bagian ini dengan teknologi yang digunakan di dalam repositori)*

- **Frontend:** HTML5, CSS3, JavaScript *(atau React / Vite / Tailwind CSS)*
- **Icons & Assets:** FontAwesome / Lucide Icons / Google Fonts
- **Deployment:** GitHub Pages / Vercel / Netlify
